\# Chefer | Restaurant



A modern and responsive restaurant website UI/UX project designed for \*\*Chefer | Restaurant\*\*.



The website provides an elegant digital experience for presenting the restaurant, menu, team, blog, testimonials, and contact information.



\## Features



\- Modern restaurant website design

\- Responsive layout for desktop, tablet, and mobile

\- Hero section with call-to-action

\- About Us section

\- Restaurant menu

\- Restaurant team section

\- Blog section

\- Customer testimonials

\- Contact page

\- Responsive navigation

\- Image galleries and sliders

\- Interactive UI components



\## Pages



\- `index.html` — Home page

\- `about.html` — About the restaurant

\- `menu.html` — Restaurant menu

\- `team.html` — Restaurant team

\- `blog.html` — Restaurant blog

\- `testimonial.html` — Customer testimonials

\- `contact.html` — Contact page

\- `feature.html` — Features page

\- `404.html` — Custom 404 page



\## Technologies Used



\- HTML5

\- CSS3

\- JavaScript

\- Bootstrap

\- jQuery

\- Owl Carousel

\- SCSS
